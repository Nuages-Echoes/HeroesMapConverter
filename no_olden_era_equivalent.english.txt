------------------------------------------------------------
4. Types converted but collapsed to a coarser OE object (kept, not lost)
------------------------------------------------------------

  - Scenery sprite variants: many H2/H3 def variants share one OE sid
    (e.g. all pine trees -> pinetree_1/pinetree_snow_1 by biome); the
    way back recovers the family, not the exact variant.
  - Specific H3 artifacts -> OE "random-item"; random artifacts (h3
    classes 65-69) -> "random-item" as well.
  - Fixed and random monsters -> OE "random-squad" with a propSquads /
    propRandomSquads row carrying the unit sids and tier.
  - Towns and heroes -> OE "city-spawner" / "hero-spawner" (spawn-
    linked), so the H2 town race / hero class is not kept per object.
  - Roads and rivers are not OE objects: they live in the terrain layer
    (roadsMap bitfield, rivers node lists).
  - H3 Event / Sign / Seer Hut / Quest Guard objects are not OE objects
    either: they become OE quest script triggers (see the 'scripts'
    section), when their metadata can be expressed there.
