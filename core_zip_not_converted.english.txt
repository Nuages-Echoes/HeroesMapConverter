H3/H2 items the game Core.zip does NOT obviously convert to Olden Era
=====================================================================

Sources: Core.zip (DB/items/items/*.json, DB/heroes_skills/skills/skills.json,
DB/map/objects/6_artifacts.json, Lang/english/*), the local references and
oe_object_correspondence.json. "Obvious" = exact match on the English display
name (artifacts) or on the skill name (secondary skills). Everything below has
no such match; the converter falls back to the coarser OE object (random-item /
random-squad / dropped) or keeps the raw id in metadata.

Converted exactly (for reference): 20 of 143 H3 artifacts, 16 of 28 H3 secondary
skills. Tables: oe_object_correspondence.json (artifact_equivalents,
skill_equivalents, oe_item_names, oe_skill_names).

------------------------------------------------------------
1. H3 artifacts with no OE artifact of the same name (123)
------------------------------------------------------------

   matching rarity (Treasure/Common=0, Minor/Rare=1, Major/Epic=2, Relic/Legendary=3),

   and 1 (Spell Scroll) are special: OE has scroll map objects (scroll_box,
   enchanted_scroll_box, mythic_scroll_box) and magic_scroll items, but the
   spell carried by a scroll still needs the H3 spell -> OE magic sid table.

------------------------------------------------------------
3. OE items/spells with no H3 counterpart
------------------------------------------------------------

   OE has 317 named items; only 20 share an H3 artifact name. The rest are OE-only
   (they convert to H2/H3 as random artifacts). OE spells (DB/magics, sids like
   day_3_magic_haste) have no H3 spell id table yet either - spell conversion is
   the next step after artifacts/skills.

------------------------------------------------------------
4. Still-unmapped H3 object classes (unchanged)
------------------------------------------------------------

   See no_olden_era_equivalent.english.txt section 1 (88 omit classes: water/boat
   objects, creature banks, battlefield terrains, quest objects, ...). Core.zip's
   DB/map/objects/*.json holds the placeable OE sids - matching those classes is
   the remaining object-level work.
